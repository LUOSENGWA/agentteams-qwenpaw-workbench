# 0.5.0-beta.8（pre-release · 首个公开版本）

AgentTeams QwenPaw Workbench 的首个公开发布。正式版尚未发布，当前处于
0.5.0-beta.N beta 通道，以 pre-release 形式发布。

## 简介

通过 QwenPaw 接入你的 AgentTeams（HiClaw）集群的团队工作台：查看与管理
**团队 / 工作流 / 项目 / 产物交付 / Worker 成员 / 3D 知识图谱**，支持在房间里
直接 @成员、审批 Worker 工具执行安全级别。插件以**控制台内联页面**与
**桌面独立窗口（PawApp）**两种形态自动生效，无需修改宿主代码。

## 功能一览

|-----|------|

| 👷 团队管理 | Worker 层级树、审批模式（工具执行安全四档：严格/智能/自动/关闭）、团队/Worker/员工（Human CR）CRD 管理与团队访问矩阵（L1），建团队时可直接新建 Worker |

## 安装

与 QwenPaw 官方插件文档一致：插件操作只能在 QwenPaw **离线**时执行。

```bash
# CLI 安装（ZIP 或 URL）
qwenpaw plugin install agentteams-qwenpaw-workbench-v0.5.0-beta.8.zip
qwenpaw plugin install https://github.com/LUOSENGWA/agentteams-qwenpaw-workbench/releases/download/v0.5.0-beta.8/agentteams-qwenpaw-workbench-v0.5.0-beta.8.zip
# 覆盖升级（后续版本）
qwenpaw plugin install <zip> --force
```

控制台：设置 → 插件管理 → 安装（选 ZIP 或粘贴 URL）。

## 配置

安装后打开工作台 → ⚙️ 配置：

1. **Controller 地址**：AgentTeams Controller API 地址（如 `http://<node>:6866`，
   支持多地址故障转移）
2. **凭据**（二选一）：
   - **L1 管理员**：粘贴 Controller admin token
     （`docker exec agentteams-controller cat /var/run/agentteams/cli-token`）
   - **L2 普通成员**：选「Matrix 登录」，填自己的 Matrix 账号（用户名 + 密码，
     入职时交付）。L2 仅能读写自己 `accessibleTeams` 范围内的数据
3. **Matrix 地址**：默认与 Controller 同机，一般无需改
4. 点 **保存并自检**——🔍 自检 tab 逐项验证 L0-L4 连通性

## 卸载

- 控制台：设置 → 插件管理 → 已安装 → 删除
- CLI：`qwenpaw plugin uninstall agentteams-qwenpaw-workbench`

QwenPaw ≥ 2.1.0（`< 2.2.0`）+ AgentTeams Controller（HiClaw 集群）。

# 0.5.0-beta.8 (pre-release · first public release)

The first public release of AgentTeams QwenPaw Workbench. No stable release is
planned near-term; the plugin is in the 0.5.0-beta.N channel and published as a
pre-release.

## Overview

A team workbench for AgentTeams (HiClaw) clusters through QwenPaw: manage
**teams / workflows / projects / artifact delivery / worker members / 3D
knowledge graph**, with in-room @mentions and approval of worker tool-execution
security levels. Works both as an **in-console page** and a **desktop app window
(PawApp)** — no host code changes required.

## Features

| Tab | Capabilities |
|-----|--------------|
| 🏠 Home | Teams / tasks / workers / artifacts / recent activity / cluster load overview + pending-approval cards (approve/deny via the host's native approval chain) + quick actions |
| 💬 Chat | Team room chat (direct Matrix), thread panel, member detail cards, room favorites / mute / leave / delete, message search, @mentions |
| 🔔 Notifications | Notification center (aggregated inbox of @mentions / task progress; click to jump to the room and locate the message) |
| 🔀 Workflows | Three views (list / card / board) + project task graph (pause / resume / replan / cancel / complete) |
| 📦 Artifacts | Project artifact file tree + online preview + download |
| 👷 Team Management | Worker hierarchy tree, approval mode (4 tool-execution security levels: strict / smart / auto / off), Team / Worker / Human CRD management + team access matrix (L1), create workers while creating teams |
| 📚 Knowledge Base | Remote worker knowledge bases and local memory: browse, preview, download, 2D/3D knowledge graph |
| 🎯 Skills | Host agent skill management (SkillPool) |
| 🔍 Self-check | L0-L4 connectivity self-check (Matrix / Controller / MinIO / Worker / KB) |
| 🛠️ Ops | Cluster load (SGLang /v1/loads), container logs (L1) |
| ⚙️ Config | Controller address / credentials (L1 admin token / L2 Matrix login), Matrix address, dark theme, start-page toggle |

## Installation

Consistent with the official QwenPaw plugin docs: plugin operations can only be
performed while QwenPaw is **offline**.

```bash
# CLI install (ZIP or URL)
qwenpaw plugin install agentteams-qwenpaw-workbench-v0.5.0-beta.8.zip
qwenpaw plugin install https://github.com/LUOSENGWA/agentteams-qwenpaw-workbench/releases/download/v0.5.0-beta.8/agentteams-qwenpaw-workbench-v0.5.0-beta.8.zip
# in-place upgrade (future versions)
qwenpaw plugin install <zip> --force
```

Console: Settings → Plugin Manager → Install (pick the ZIP or paste the URL).

## Configuration

Open the workbench → ⚙️ Config:

1. **Controller address**: the AgentTeams Controller API address (e.g.
   `http://<node>:6866`; multi-address failover supported)
2. **Credentials** (choose one):
   - **L1 admin**: paste the Controller admin token
     (`docker exec agentteams-controller cat /var/run/agentteams/cli-token`)
   - **L2 regular member**: select "Matrix login" and enter your own Matrix
     account (username + password, delivered at onboarding). L2 can only
     read/write data within its `accessibleTeams` scope
3. **Matrix address**: defaults to the same host as the Controller; usually no
   change needed
4. Click **Save & self-check** — the 🔍 Self-check tab verifies L0-L4
   connectivity item by item

## Uninstall

- Console: Settings → Plugin Manager → Installed → Remove
- CLI: `qwenpaw plugin uninstall agentteams-qwenpaw-workbench`
