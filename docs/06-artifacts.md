# 产物与项目

项目交付物的一屏聚合：项目产物（Controller 正源）+ 房间附件（房间侧兜底扫描）。

## 两个数据面

| 面 | 内容 | 来源与条件 |
|----|------|-----------|
| **项目产物（正源）** | 经 projectflow 登记的项目的交付物，按项目/分类组织，可文件预览 | Controller API。**L1 token 配置后可见全部**（含 Leader 创建、你不在其房间内的项目）；未配置/无效 token 时显示「未接通」警示条 |
| **房间附件** | 团队房间里发的文件，按房间/时间扫描聚合 | Matrix 房间消息——不依赖 Controller 项目登记，未登记项目只有这一条路 |

> 版本注意：Controller 未升级到含项目产物的版本时正源 404 → 页面自动只显示房间附件（提示条说明原因），不会报错。

## 项目操作

对可访问的项目（L2 限本账号可访问范围，L1 全量）：

- **启动 / 暂停 / 恢复** 项目（写操作，视 Controller 版本能力，未支持时按钮不出现）
- **产物** 直达本页对应项目

## 文件预览

点击文件 → 预览（文本/Markdown 渲染；二进制显示元信息）。项目产物与房间附件共用同一预览组件。

## 常见情况

- 「暂无已登记项目——经 projectflow 登记的项目会显示在这里」：团队还没走 projectflow 登记流程，房间附件仍正常显示
- 「该分类下还没有文件」：分类筛选下为空，换分类或看全部
- 正源未接通警示条：去 [配置参考](./12-config.md) 填 L1 token
