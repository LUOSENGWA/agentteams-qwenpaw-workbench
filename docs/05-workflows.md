# 工作流

团队任务/工作流的执行视图。数据源 = Controller 的 projects/workflows（L2 限可访问项目）。

## 四种视图（Segmented 切换，视图选择跨刷新记忆）

| 视图 | 适合看什么 |
|------|-----------|
| 📋 **事件** | 时间序事件流——某个工作流发生了什么，按序回放 |
| 🗂️ **卡片** | 每工作流一张卡——状态/阶段/负责人速览 |
| 📊 **看板** | 任务按阶段分列（计数实时）——团队负载与阻塞点 |
| 🌳 **拓扑** | 运行拓扑力导向图（节点数实时）——派发链与执行结构 |

- 当前视图与拓扑选中的 runId **持久化在页面状态里**——刷新/切大 tab 不丢
- **15s 自动刷新**（v0.5.0-beta.12 起，A1，对齐 dashboard `refetchInterval:15000`）：仅工作流 tab 激活时静默轮询（切走即停，不闪页）
- 拓扑里选的 runId 失效（工作流结束/重建）时自动兜底到第一个有节点的工作流，不会白屏

## 拓扑视图细节

- 每个工作流一棵执行树：节点 = 执行节点（Worker 任务单元，按 spawn 正源填充），边 = 派发/依赖关系
- 有节点的工作流才进拓扑视图（Segmented 上的计数即「有拓扑的工作流数」）
- 点击节点查看详情

## 与其他页的关系

- 首页「任务进展」卡 = 工作流的计数摘要，点进去就是这里
- 产物页按项目聚合交付物，工作流是过程、产物是结果
- L2 用户只能看到自己账号可访问的项目；L1 全量
