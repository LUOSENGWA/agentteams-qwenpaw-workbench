# 5 分钟上手

## 第一步：打开插件页

装完插件后，控制台首页会出现 **AgentTeams Workbench** 入口，点击即进。也可从 PawApp 桌面窗口打开。

## 第二步：配置（Settings tab）

配置页三组输入：**Matrix 地址（必填）→ 认证模式（二选一）→ Controller 地址（可选）**。

### ① Matrix 地址（必填至少一个）

内网 + 外网两个入口（可只填一个）。内外网是同一服务器的两条访问路径，**无需手动切换**——插件自动定期重测全部地址（测延迟），自动切到最快可达的一条，内/外网切换自动识别。

### ② 认证模式（二选一）

| 模式 | 要什么 | 能做什么 | 适合谁 |
|------|--------|----------|--------|
| **Matrix 登录（L2，默认）** | 自己的 **Matrix 账号 + 密码**（入职时交付，登录后显示「当前身份」） | 查看本账号可访问的团队；项目操作（启动/暂停/产物）；聊天 / 审批 / 通知 / 知识库全可用 | 团队日常成员（L2 Human） |
| **管理员 token（L1）** | 粘贴服务器端 `/var/run/agentteams/cli-token` 文件内容（一次性，保存后永久记住） | L2 全部 + CRD 管理（入职/建队/改配/删除）+ 全部 Worker/Team 状态视图 + 集群负载 | 部署管理员 / 集群 Owner |

> 注意：Controller 的 Matrix 认证只接受**权限等级 2（level 2）的 Human 账号**——level 1 的 admin 账号会 401。如果你的 Matrix 账号是 admin，请用 L1 token 模式，或让部署管理员把该 Human 改为 level 2（权限自检可见当前账号等级）。

### ③ Controller 地址（可选）

- **全量团队视图才需要**。填 1 个或多个地址（如 `http://<node>:8090`），保存时自动逐个测延迟、切到最快，之后后台自适应重测（稳定时低频；单地址不探测）。
- 不填：插件走房间侧数据（聊天/审批/附件扫描仍可用），跨团队的项目/产物总览不可用。

点**保存并自检**——🔍 自检 tab 逐项验证 L0-L3。保存后配置持久化在本机（浏览器 + 插件后端），重启不丢。

## 第三步：开工

- **首页**：看团队/任务/审批全局概览，点「发起任务」选 Leader 派发
- **聊天**：进入团队群聊，@ 成员协作
- **团队管理**：看团队结构与 Worker 状态，编辑模型配置
- **自检**：随时 L0-L3 分层体检

## 权限速查（L1 vs L2）

| 能力 | L2（Matrix） | L1（token） |
|------|:---:|:---:|
| 团队/Worker 列表（本账号可访问范围） | ✅ | ✅ |
| 聊天 / 审批 / 通知 / 知识库 | ✅ | ✅ |
| 项目操作（启动/暂停/产物） | ✅（可访问项目） | ✅ |
| CRD 管理（建队/入职/改配/删除） | ❌ | ✅ |
| 全量 Worker/Team 状态 | ❌ | ✅ |
| 集群负载（SGLang/GPU） | ❌ | ✅ |
| 技能矩阵 / MCP 矩阵写入 | 限本团队 | 全量 |

完整矩阵见 [配置参考](./12-config.md)。
