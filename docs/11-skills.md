# 技能中心与 MCP

团队技能的统一面（团队管理 →「技能中心」，三个折叠节）+ 本机宿主技能（独立 tab）。

## 技能中心三节

### ① 技能目录（只读）

Controller 侧技能清单（`GET /api/v1/skills`）——集群里有哪些技能可用。
**依赖上游 PR #1211 合并**：未合并时显示 404 占位卡（预期行为，不是故障）。

### ② Worker × 技能分配矩阵

行 = Worker，列 = 技能，勾选 = 分配/回收。

- 已分配**反显**（打开即真实状态，不是空表单）
- 保存走 `PUT /workers` 的 skills 字段（**合并语义**——只改技能字段，不动 Worker 其他配置）
- **权限**：L1 可写；L2 限本团队；被拒（403/404）时明确提示原因，不静默失败

### ③ MCP Servers 矩阵

MCP Server 清单与分配：**name / url / transport 行内编辑**，L1 可写。

## 宿主技能（独立 tab）

「宿主技能」= **本机 QwenPaw 实例自己的 SkillPool**（宿主的技能），不是 Worker 的团队技能——v0.5.0-beta.11 从「技能」更名以示区分，首页有快捷入口。

## 常见情况

- 矩阵打开是空的：该 Worker 未分配技能（或 L2 下不在本团队范围）
- 保存被拒：提示里带 403/404 原因（权限不足 / Controller 版本未支持）
- 技能目录是占位卡：等上游 #1211 合并后自动点亮，无需升级插件
