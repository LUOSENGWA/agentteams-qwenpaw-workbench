# 知识库

团队知识的浏览、搜索与图谱：本地（宿主）与远端（团队 Agent）文件统一一屏，跨 Agent 搜索，2D/3D 力导向知识图谱。

## 文件浏览（四分类）

对齐 QwenPaw 最新版文件管理的四分类：

| 分类 | 内容 |
|------|------|
| 📄 文件 | 普通文件 |
| 🗄️ 档案 | 归档资料 |
| 📔 日记 | 日记/日志类 |
| 📚 知识库 | 知识沉淀（MEMORY/digest 等） |

- 每个文件带**来源标识**：本地（宿主工作区）或远端（团队 Agent workspace），两套分类配色区分
- 团队 Agent 的 workspace 经 Controller 代理读取（L2 限本团队）

## 跨 Agent 搜索

- 一个搜索框搜**全部可访问 Agent** 的知识文件（`/kb/search`）
- 结果带来源 Agent 标识，点开进文件预览

## 知识图谱（2D/3D 力导向）

- **团队聚合图谱**：按团队聚合全部成员的知识链接（`/kb/graph/merged`），页内团队 Select 切换（默认当前 Agent 所在团队）
- **2D / 3D 双模式**：3D 需 WebGL，浏览器不支持时**自动回退 2D**（不报错）
- 节点分级配色：根（虚拟分类根，橙色）/ 分类 / 文件；**节点大小 = 链接度**
- **点文件节点直接开文件预览**（2D/3D 均可；虚拟根/未解析引用保持提示）
  - 慢响应不会覆盖你后来的点击（请求序号守卫）
  - 再次点击同一节点 = 刷新预览
  - 3D 轻点（<5px 且 <500ms）识别为点击，拖拽旋转视角不误触发

## 权限

- L2：本账号可访问团队的文件/图谱
- L1：全量团队
