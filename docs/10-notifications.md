# 通知

聚合收件箱：房间里 @你、任务进展、审批请求、房间邀请——一屏汇总，点击直达现场。

## 通知类型

| 类型 | 来源 | 点击行为 |
|------|------|----------|
| 📣 房间 @你 | 团队房间里的 mention（主判据 `m.mentions.user_ids` + 正文兜底） | 直达该房间并定位消息 |
| 🛡️ 审批请求 | Worker Tool Guard 审批 | 直达审批现场（可一键批/拒，见 [审批](./09-approvals.md)） |
| 📊 任务进展 | 工作流状态变化 | 直达工作流视图 |
| ✉️ 房间邀请 | 被邀请进新房间 | 直达团队管理邀请区（单一事实源：接受/拒绝在那里完成） |

- 通知中心卡片**点击即跳转**（v0.5.0-beta.11）
- 通知 tab 标签上有未读角标；首页快捷入口显示「审批与房间 @你」未读数
- 静音房间的通知不推（与 @我 同语义）

## 桌面提醒（toast）

- 新审批请求 / 新房间邀请：桌面 toast 立即弹出（不等进页面）
- **离线补检**：插件后端 sync 常驻，你离线（关页面/断网/关机）期间发生的 @你、审批、邀请，回来后**首轮 sync 全量补检**——不丢

## 基线抑制

首次建立房间基线时（刚完成配置、第一次 sync 全量拉历史），存量旧 @/旧邀请**不通知**——只提醒基线之后新发生的事，避免历史消息轰炸。
