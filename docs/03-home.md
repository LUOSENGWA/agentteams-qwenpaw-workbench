# 首页

一屏看全队：团队、任务、审批、集群负载，以及四个高频操作的直达入口。

## 布局

```
┌ 团队协作总览 ────────────────────────────┐
│  👥 团队      📋 任务进展     🛡️ 待审批  │
│  (L1: 集群负载卡，可选)                   │
├──────────────────────────────────────────┤
│ [发起任务]  [进入团队群聊]  [通知]  [知识图谱] │
└──────────────────────────────────────────┘
```

## 概览卡

| 卡 | 内容 | 数据来源 |
|----|------|----------|
| 👥 团队 | 团队/Worker 数量与状态摘要（L1 为全量，L2 为可访问范围） | Controller + 房间基线 |
| 📋 任务进展 | 进行中任务/工作流计数 | Controller projects |
| 🛡️ 待审批 | **房间审批源 = Worker Tool Guard 真实队列**（不是宿主收件箱快照）：有请求时桌面 toast 提醒，卡内可一键批准/拒绝 | Matrix 房间 sync 检出 |
| 集群负载（可选） | SGLang/GPU 负载（**L1 专属**；后端未启用时 404 → 卡片不渲染，不报错） | Controller `/api/v1/status`（与 dashboard cluster-status 同源） |

## 快捷入口

- **发起任务**：弹窗选 Leader 派发新任务。房间基线未建立时（如刚配置完成）弹窗只保留 Manager 入口，团队管理页顶部会显示警示横幅，建好房间基线后恢复全入口
- **进入团队群聊**：直达聊天页（有未读时显示未读数）
- **通知**：直达通知中心（显示「审批与房间 @你」的未读数）
- **团队知识一屏览 / 团队技能与 MCP 矩阵**：直达知识库图谱 / 技能中心

## 待审批卡说明

- 审批请求来自 Worker 在**房间**里发的 Tool Guard 审批消息（真实队列，离线期间首轮 sync 会补检）
- 卡上批准/拒绝按钮发出的命令**带三重 `` 标记**——群房间无 mention 的命令不进 Worker 消费队列（详见 [审批](./09-approvals.md)）
- 宿主 2.1+ 上，同一审批还会出现在**宿主收件箱**（导航抖动 + 红点 + 审批条目）——两条路都能批，批一次全链路闭环（见 [审批 §宿主收件箱桥](./09-approvals.md)）
